<h2><a href="https://www.geeksforgeeks.org/problems/check-binary-string0402/1">Check for 0 Between 1's in Binary String</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a binary string <strong>s</strong> consisting of '0' and '1', determine whether it is valid such that no '0' appears between two '1's. </span></p>
<p><span style="font-size: 18px;">Return <strong>true</strong> if valid, otherwise return <strong>false</strong>.</span></p>
<p><strong style="font-size: 18px;">Examples:</strong></p>
<pre><span style="font-size: 14pt;"><strong>Input</strong>: s = "100"
<strong>Output</strong>: true
<strong>Explanation</strong>: The string contains only one '1', so no `'0' appears between two '1's', hence it is valid.
</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input</strong>: s = "1110001"
<strong>Output</strong>: false
<strong>Explanation</strong>: The string has '0' occurring between '1's, so it is not valid.
</span></pre>
